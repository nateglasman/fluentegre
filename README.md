# fluenteGRE

**The bilingual GRE vocabulary trainer for Spanish, Portuguese, and Italian speakers.**

[fluentegre.me](https://fluentegre.me)

## What is this?

fluenteGRE helps non-native English speakers master GRE vocabulary using their native language as a bridge. Every word includes a translation, native-language definition, and a mnemonic trick that connects both languages.

## Features

- **1,184 GRE words** across 31 study sets, organized into 23 thematic groups
- **Bilingual flashcards** with spaced repetition (Again / Hard / Good / Easy)
- **3 quiz modes** — definition matching, translation quiz, timed pair matching
- **Full translations** in Spanish, Portuguese, and Italian — each with definitions and memory tricks in the target language
- **Progress tracking** with per-word mastery scores, streak counting, and group-level analytics
- **Keyboard shortcuts** — Space to flip, 1-4 to rate
- **No signup, no backend** — runs entirely in the browser, progress saves to localStorage
